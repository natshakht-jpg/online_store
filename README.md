# Интернет-магазин на Django

## Описание
Проект интернет-магазина. Реализованы каталог товаров, страница контактов с формой обратной связи, 
админка, работа с PostgreSQL, фикстуры, кастомные команды, пагинация, форма добавления товаров.

## Как запустить
1. Установить зависимости: `pip install -r requirements.txt`
2. Создать файл `.env` в корне проекта и прописать настройки PostgreSQL:
DATABASE_NAME=online_store_db
DATABASE_USER=myuser
DATABASE_PASSWORD=ваш_пароль
DATABASE_HOST=localhost
DATABASE_PORT=5432
3. Выполнить миграции: `python manage.py migrate`
4. Загрузить тестовые данные: `python manage.py load_products`
5. Создать суперпользователя: `python manage.py createsuperuser`
6. Запустить сервер: `python manage.py runserver`
7. Открыть в браузере: `http://127.0.0.1:8000/`

## Реализовано
- Главная страница (последние 5 продуктов)
- Страница контактов с формой обратной связи и контактными данными (модель `Contact`)
- Обработка POST-запроса, вывод данных в консоль
- Админка с настройками отображения, фильтрами и поиском
- PostgreSQL, переменные окружения (`.env`)
- Фикстуры для категорий и продуктов
- Кастомная команда `load_products`
- Bootstrap для стилизации
- Главная страница с пагинацией (по 3 товара на страницу)
- Страница товара (полная информация)
- Форма добавления новых товаров 
- Базовый шаблон base.html и наследование
