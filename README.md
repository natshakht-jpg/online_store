# Интернет-магазин на Django

## Описание
Учебный проект интернет-магазина. Реализованы главная страница и страница контактов с формой обратной связи.

## Как запустить
1. Установить зависимости: `pip install -r requirements.txt`
2. Выполнить миграции: `python manage.py migrate`
3. Запустить сервер: `python manage.py runserver`
4. Открыть в браузере: `http://127.0.0.1:8000/`

## Реализовано
- Главная страница (каталог товаров)
- Страница контактов с формой обратной связи
- Обработка POST-запроса, вывод данных в консоль
- Bootstrap для стилизации
