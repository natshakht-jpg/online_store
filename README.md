# Интернет-магазин на Django

## Описание
Учебный проект интернет-магазина. Реализованы каталог товаров, блог, страница контактов с формой обратной связи, админка, работа с PostgreSQL, фикстуры, кастомные команды, пагинация, форма добавления товаров, отображение изображений, подшаблон меню.

## Как запустить
1. Установить зависимости: `pip install -r requirements.txt`
2. Создать файл `.env` в корне проекта и прописать настройки PostgreSQL:
DATABASE_NAME=online_store_db
DATABASE_USER=myuser
DATABASE_PASSWORD=ваш_пароль
DATABASE_HOST=localhost
DATABASE_PORT=5432

3. Выполнить миграции: `python manage.py migrate`
4. Загрузить тестовые данные: `python manage.py load_products`
5. Создать суперпользователя: `python manage.py createsuperuser`
6. Запустить сервер: `python manage.py runserver`
7. Открыть в браузере: `http://127.0.0.1:8000/`

## Реализовано

### Каталог (переведён на CBV)
- Главная страница с пагинацией (по 3 товара) и картинками товаров — `ProductListView`
- Страница товара (полная информация + картинка) — `ProductDetailView`
- Форма добавления новых товаров с возможностью загрузки изображений — `ProductForm`
- Страница контактов с формой обратной связи и контактными данными (модель `Contact`) — `ContactView`

### Блог (полный CRUD через CBV)
- Список опубликованных статей (`BlogListView`) — выводятся только записи с `is_published=True`, пагинация (по 5 на страницу)
- Детальная страница статьи (`BlogDetailView`) — отображается заголовок, содержимое, превью (изображение) и счётчик просмотров
- Создание статьи (`BlogCreateView`) — форма с полями: заголовок, содержимое, превью, признак публикации
- Редактирование статьи (`BlogUpdateView`) — форма с теми же полями
- Удаление статьи (`BlogDeleteView`) — страница подтверждения удаления
- Счётчик просмотров увеличивается при каждом открытии статьи
- В главном меню добавлена ссылка на блог
- **Дополнительно:** при достижении 100 просмотров статьи отправляется письмо на почту (файловый бэкенд, письма сохраняются в папку `sent_emails`)

### Формы и валидация
- Полный CRUD для продуктов (создание, чтение, обновление, удаление)
- Валидация формы `ProductForm`:
  - Запрещённые слова в названии и описании (казино, криптовалюта, крипта, биржа, дешево, бесплатно, обман, полиция, радар) — регистр не важен
  - Цена не может быть отрицательной
  - Изображение: только форматы JPEG, JPG, PNG, размер не более 5 МБ
- Стилизация формы через Bootstrap (классы `form-control`, плейсхолдеры)
- Обновление и удаление товаров через отдельные страницы (`/products/<id>/edit/`, `/products/<id>/delete/`)

### Общее
- Админка с настройками отображения, фильтрами и поиском (для каталога и блога)
- PostgreSQL, переменные окружения (`.env`), `psycopg2-binary`
- Фикстуры для категорий и продуктов, кастомная команда `load_products`
- Базовый шаблон `base.html`, подшаблон `menu.html` через `{% include %}`
- Bootstrap для стилизации
